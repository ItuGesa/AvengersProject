AVENGERS UNIVERSE- Interactive Website

An interactive, multi-page Avengers-themed website built using HTML, CSS and JavaScript. 
This project explores front-end web development through character profiles, movie pages,
image galleries and interactive navigation.

PROJECT OVERVIEW
The Avengers Universe project is a fan-made website that brings together information about Marvel's
Avengers characters and movies in one place.
The website features individual character pages, movie-related pages and an interactive rotating 
image gallery that allows visitors to explore the Avengers universe.
It was developed as a practical front-end development project to strengthen my understanding of
website structure, styling and JavaScript interactions.

FEATURES
- Interactive Image Gallery: A rotating 3D-style image gallery featuring Avengers-related images.
- Image Navigation: Previous and next controls for navigating through the gallery.
- Image Preview: Click on gallery images to display an enlarged image overlay.
- Character Pages: Dedicated pages for characters including Iron Man, Thor, Hulk, Captain America, Black Widow and Hawkeye.
- Movie Pages: Separate pages exploring selected Avengers-related movies.
- Multi-page Navigation: Links connecting the different sections of the website.

TECHNOLOGIES USED
- HTML: Website structure and content.
- CSS: Styling, layout and gallery presentation.
- JavaScript: Gallery interactions and image previews.
